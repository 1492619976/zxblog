# 尚硅谷AI大模型课程体系盘点（E盘落位）

## 是什么
尚硅谷大模型全家桶一套 27 个目录：**基础层(01~11) → 大模型技术层(12~16) → 项目与进阶层(17~27)**。视频课为主，大头是四个大模型项目（17/19/22/24）。另有数据平台方向的中级认证考试（非本套课程）。

## 三层结构
- **01~11 AI基础前置**（合计仅~260MB，全是笔记/手册）：python基础、数据结构算法、Linux+Shell、MySQL、Docker、Numpy+pandas、机器学习、深度学习、NLP、web开发、智能商品推荐小项目。定位=查漏补缺速查层，不必从头刷
- **12~16 大模型入门**：大模型概述(docx)、低代码平台agent（Coze&Dify 搭 RAG 知识库+智能体+企业部署，1.6G）、LangChain、LangGraph(V1.1.0 docx)、Git
- **17~27 项目+进阶**（74GB 大头）

## 四大项目（核心资产）
| 项目 | 定位 | 技术要点 |
|---|---|---|
| 17掌柜智库(+18实战) | doc RAG 知识库，10天22G | PDF解析→文档标题/精细切割→图片语义识别→三路检索→reranker→SSE输出；MongoDB；带《高频面试题.docx》 |
| 19 DeepAgents | LangChain DeepAgents 框架，2天 | 规划/工具/子代理编排，扩展实战 |
| 22电商小二(+23实战) | 电商客服 Agent，11G | uv+nodejs 现代工具链、MySQL |
| 24掌柜问数(+25实战) | **NL2SQL 的 DB RAG**，7G | 元数据库MySQL + 字段/指标向量索引qdrant + 字段值全文索引ES → LLM生成SQL查数仓；两阶段=索引/检索；自带Claude Code安装配置课 |

- 实战版(18/23/25)=训练营作业包：教育/旅游/听书/育儿/金融选一行业按需求说明.md 自练，允许 vibe coding，交作业制
- 技术课：20 LLM原理(12G docx V1.2.1)、21强化学习、26多模态、27评估优化+部署（含 vibecoding 章节）

## 对口分析（DataAgent 方向）
- **24 掌柜问数与目标最对口**：NL2SQL/ChatBI 正是 DataAgent 岗的核心能力项，且与指标口径查询 DataAgent 落地构想同构（元数据+向量检索+生成SQL）
- 17 掌柜智库 RAG 是 Agent 岗通用底座，自带面试题，练手素材现成
- 学习顺序建议（已在 Python 主线时的旁线补充）：12概述 → 14 LangChain → 15 LangGraph → 24问数；01~11 只当速查手册
- 注意：不打乱 **三线总计划** 的 4 个月主计划节奏，本套作为项目参考与补强素材
