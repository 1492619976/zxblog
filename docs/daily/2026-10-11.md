### Python 变量 = 名字标签，类型跟着对象走

赋值不是"装进盒子"，是"给东西贴名字"——**类型是对象的属性，不是名字的属性**。`x = 100` 再 `x = "你好"`：名字没变、东西换了，完全合法，这就是"动态类型"。

```python
x = 100
print(type(x))  # <class 'int'>  ← 查的是名字当前贴着的东西
x = "你好"
print(type(x))  # <class 'str'>  ← 换贴新东西，类型跟着换
```

| 语言 | 心智模型 | `x=100` 后再 `x="你好"` |
|------|---------|----------------------|
| Java | 固定类型的盒子 | ❌ 编译报错 |
| Python | 东西 + 名字标签 | ✅ 撕标签贴新东西 |
| Oracle | x ≈ 同义词(SYNONYM)，对象 ≈ 表 | 同义词可改指向；类型属于表 |

### b = a 不拷贝：一次费曼纠错实录（盒子模型 → 标签模型）

```python
a = [1, 2, 3]
b = a
b.append(4)
print(a)   # [1, 2, 3, 4]
```

初答错了（答 `[1,2,3]`，理由"没给 a 重新赋值"）——这是 Java 基本类型的**值拷贝**直觉。纠错类比：张三/老张是一个人，老张增重 4 公斤，喊张三称重 64kg → `b = a` 只是起别名，`append` 改的是**那个唯一的对象**。Java 对照：对象赋值两边语义相同（`List b = a; b.add(4)` 同样可见）；真正差异是 Java 有两套规则（8 种基本类型值拷贝 + 对象引用、类型定死），Python 一切皆对象只有一套。重构四句话：造东西起名 / 取别名 / 改唯一对象本身 / 打印 a 即打印同一对象。

### is 比身份，== 比内容（谁都不比 hash）

```python
a = [1, 2, 3, 4]
b = a              # 别名：同一个人
c = [1, 2, 3, 4]   # 克隆人：内容相同，另一个人
# a == b → True    a is b → True
# a == c → True    a is c → False
```

终身配对：**`is` ≈ Java 对象的 `==` ≈ ROWID 同一行（身份）**；**`==` ≈ Java `equals` ≈ 内容全同（内容）**。坑：`is` 不比 hash——hash 是 dict/set/HashMap 内部查找用的摘要编号（索引），不是比较标准；Java 方向也别记反（对象 `==` 比引用，重写后的 `equals` 比内容）。判空写 `x is None`：`==` 的相等规则是对象类自己定义的（可被重写写歪），`is` 由解释器保证，谁也改不了。

### 增重 vs 换贴：b += 1 为什么动不到 a（mutable/immutable 分水岭）

```python
a = 1
b = a
b += 1     # a 还是 1，b 变 2
```

数字不可变（石碑上刻好的 1 变不成 2），`b += 1` 只能**新造 2、把 b 的标签换贴过去**——a 原地不动。`id()` 实测：换贴前 a/b 同一对象，换贴后不是。对照列表：`b.append(4)` 是**增重**（改对象本身），a 看得到。收官规律：**改对象本身 → 所有名字可见；撕标签换贴 → 只有被撕的名字变**。跨语言通用：Java 数组改元素同样可见（增重），它不能的是加长（长度定死，想加用 ArrayList）——可变性是**对象类型**的属性，不是语言的属性。有趣对照："名字没动就不变"的直觉在数字题对、列表题错，分水岭就是可变性。

### 容器四件套 = 两族四件：序列靠位置，散列靠钥匙

list（有序清单/结果集/能增重）、tuple（石碑/表的一行/数据库驱动原生返回）、dict（钥匙→值/带列名的一行/JSON 的形状）、set（去重袋子/会动的 DISTINCT）。dict 键必须不可变——石碑（tuple）才有资格当钥匙。对账一行流：`漏报送 = src - sent`（差集），交集 `&` 并集 `|`。分层记忆：list/tuple 像贴源明细，dict 像带名记录，set 像校验层去重统计。四坑：单元素 tuple 写 `(1,)`；KeyError 用 `.get(k, 默认)`（≈NVL）；空 set 写 `set()`（`{}` 是空 dict）；set 无序无下标。查库结果转 dict 标准姿势：**`dict(zip(列名, 行))`**（拉链按位置咬合成键值对，列名来自 `cursor.description`），整批 = `[dict(zip(cols, r)) for r in rows]` → list 装 dict。

### 推导式 = SQL 换装：读序就是逻辑执行顺序

```python
# SELECT 客户号 FROM rows WHERE 金额 > 4000
[r[0] for r in rows if r[2] > 4000]
```

槽位对照：开头 = SELECT 列，`for r in` = FROM + 行别名（循环变量 = 当前行，锚 PL/SQL 游标 `FOR rec IN`），`if` = WHERE。**读的顺序 = SQL 逻辑执行顺序：FROM → WHERE → SELECT，即先读 for、再读 if、最后读开头**。花括号版 `{r[0] for r in rows}` 直接产 set。坑：list 的 `b += [4]` 是原地扩展（增重，a 可见），`b = b + [5]` 才是换贴——**`+=` 的行为由对象可变性决定**。
