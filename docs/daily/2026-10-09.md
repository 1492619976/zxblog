### Python 基本数据类型

1. 数值：`int`、`float`、`complex`（复数）；布尔 `bool` 是 int 的子类
2. 字符串 `str`
3. 容器类型：列表 `list`、元组 `tuple`、集合 `set`、字典 `dict`
4. 特殊类型 `None`：表示空值或缺失值

### 类型转换：隐式与显式

- 自动类型转换（隐式）：不同类型运算时，较小的数据类型自动转为较大的，避免数据丢失
- 强制类型转换（显式）：`int()` / `float()` / `str()` 等手动转换

### 运算符速览

- 算术：`+ - * / % ** //`
- 赋值：`= += -= *= /= //= %= **=`

- 逻辑：`and or not`

### 异或 `^`：找只出现一次的数字

两个位不同为 1，相同为 0（异为 1，同为 0）。`nums = {4, 1, 2, 1, 2}`，1 和 2 各出现两次，4 只出现一次——

```java
int xor = 0;        // 起手 0：因为 x^0=x，0 不影响结果（相当于加法从 0 开始加）
for (int v : nums)  // 增强 for 循环：每轮从 nums 取一个元素放进 v
    xor ^= v;       // 复合赋值，等价于 xor = xor ^ v
```

| 轮次  | v   | 实际计算  | xor 值   |
| --- | --- | ----- | ------- |
| 起手  | —   | —     | 0       |
| 1   | 4   | 0 ^ 4 | 4       |
| 2   | 1   | 4 ^ 1 | 5       |
| 3   | 2   | 5 ^ 2 | 7       |
| 4   | 1   | 7 ^ 1 | 6       |
| 5   | 2   | 6 ^ 2 | **4 ✓** |

### 按位与 `&`：检查或去除某些位

每一位都在问"两个都是 1 吗"，都是 1 才得 1——比如 `n & 1` 判断奇偶。

### `in` 与 `is` 的区别

- `in` / `not in`：元素是否在序列中（如 `2 in nums`）
- `is` / `is not`：两个变量是否指向同一个对象（`==` 比较的是值）

### 流程控制

#### 分支

- 分支流程又叫条件控制语句或选择语句，通过条件判断决定执行哪段代码
- 单分支 `if`；多分支 `if / elif / else`——Python 写作 **`elif`**，没有 Java 的 `else if` 两词拼法（从 Java 过来最容易顺手写错的一处）
- `match case`：match 后的对象依次与各 `case` 匹配，命中则执行对应语句，否则跳过；`case _` 兜底匹配一切（≈ Java switch 的 default，Python 3.10+ 才有）

```python
match x:
    case a:
        语句1
    case b:
        语句2
    case _:
        语句3
```
