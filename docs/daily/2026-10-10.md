### While 循环：先判断后执行的"当型"循环

先判断条件是否成立，成立才进循环体，执行完回来再判——条件一开始就不成立，那一次都不执行。

```python
i = 1
total = 0
while i <= 100:
    total += i
    i += 1        # ← 忘了这句就是死循环：条件永远成立
print(total)      # 5050
```

- **死循环 = 条件里的变量忘了更新**：相当于 `WHERE 1=1` 永真，区别是 SQL 秒回一个结果，while 不会自己停
- **Python 没有 do-while**（先斩后奏型）：要"至少执行一次"就 `while True:` 起手，满足条件后 `break` 跳出
- **for 与 while 怎么选**：已知次数（跑 100 遍）用 `for i in range(...)`；未知次数（读到文件尾、队列取空）用 while——for 是"数着做"，while 是"看着做"
- Java 对照：写法一模一样（`while (i <= 100)`），区别只是 Python 条件不用括号、代码块靠缩进
