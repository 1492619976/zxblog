# 24 掌柜问数解读要点速记（NL2SQL 的 DB RAG）

> 完整解读：`E:\AI解读文档\24-掌柜问数\`（解读.md + 图解讲义.html v1.0）

## 骨架（背）
- **两阶段**：索引（数仓元数据→meta库+qdrant向量+ES全文）/ 检索（多路召回→过滤→生成SQL→EXPLAIN校验→执行）
- **13节点**：extract_keywords → 三路并行召回(column/metric/value) → merge(补主外键) → 二路过滤(table/metric) → add_extra_context(日期+方言) → generate_sql → validate_sql →条件边→ correct_sql / execute_sql
- 智库=doc RAG，问数=db RAG

## 关键口径
- 字段+指标→qdrant**语义**；维度字段值→ES**字面**；Qdrant 不产向量（HF Embedding 产）
- 只对维度角色字段建 ES 索引；meta四表=table/column/metric/column_metric（指标卡片库的结构化版）
- generate_sql 六军规：禁编造/口径优先/只读/方言/单条/纯文本无```包裹
- validate 用 EXPLAIN 不执行；temperature=0（SQL要稳定不要创意）
- stream_mode=custom + stream_writer → SSE 推进度；ContextVar 存 request_id（协程隔离，代理不存数据）
