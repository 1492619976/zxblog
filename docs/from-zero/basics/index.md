## 两个贯穿的学习模型

**1. 换皮 vs 新大陆**：和已知概念能对上的（比如 dict 取值像 SQL 精确匹配），是"换皮"，先猜再学；完全没见过的（比如生成器），是"新大陆"，先讲再练。用错策略是低效学习的根源。

**2. 学习 = 极致重复 × 刻意练习 × 复盘**：三者是乘法不是加法——重复练本质而非原题，练习要刻意脱离舒适区，复盘要落盘可见。这个公式贯穿整个基础线。
