# 🛠️ 项目线

基础线的终点是这里：**亲手写出来的完整作品**。每篇包含设计思路、完整代码、踩坑记录和复盘——拒绝"片段演示"，要的是能跑的东西。

## 系列 #1：从 0 到 1 写 Agent 内核（Python）

> **教材**：OpenHands 的 Python 内核 [software-agent-sdk](https://github.com/OpenHands/software-agent-sdk)（开源）。
> **目标**：不吃别人喂的框架——从 `while` 循环开始，亲手写出能跑的迷你 Agent 内核，把"Agent 到底是什么"从概念变成手感。

| 单元 | 主题 | 一句话 | 状态 |
|---|---|---|---|
| U1 | 全景 | agent = while 循环 + 工具箱 | 🔥 进行中 |
| U2 | 会话与事件流 | 事件 = 不可变明细账（事件溯源） | ⬜ 未开始 |
| U3 | LLM 调用层 | messages = 带角色的对话账本 | ⬜ 未开始 |
| U4 | 一轮 step 解剖 | 压缩 → 调模型 → 解析工具调用 → 执行 → 回填 | ⬜ 未开始 |
| U5 | 工具系统 | 注册工具 = UDF 注册进元数据 | ⬜ 未开始 |
| U6 | 状态机与兜底 | RUNNING / STUCK / 审批门 / 预算限额 | ⬜ 未开始 |
| U7 | 进阶（轻讲） | condenser 长对话压缩、并行工具执行（只讲思想） | ⬜ 未开始 |
| U8 | 收官 | 亲手写 300 行迷你内核，串起 U1-U6 | ⬜ 未开始 |

**为什么 SQL/数仓背景的人学 Agent 有优势**：类比是现成的——

- 会话与事件流 = ODS 不可变明细账
- LLM 调用层 = JDBC（换模型 = 换数据库驱动）
- 工具注册 = UDF 注册进元数据
- 状态机与审批门 = ETL 作业调度 + 告警 + 资源限额

每个单元的笔记都会**先给类比、再给代码**。
