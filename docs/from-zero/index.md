# 🚀 从 0 到 1

读懂别人的代码 ≠ 会写。这个区只放一类内容：**从零开始、亲手造出来**的东西。分两条线：

| 线 | 内容 | 现状 |
|---|---|---|
| [🧱 基础线](/from-zero/basics/) | Python → 标准库实战，每个概念"讲清 + 检验题" | 进行中 |
| [🛠️ 项目线](/from-zero/projects/) | 完整做出来的作品：设计、代码、踩坑、复盘 | 第 1 个系列进行中 |

## 为什么单独开一个区

之前的笔记大多是"解读别人"——读论文、读源码、读方案，都很有价值，但那是**输入**。这个区是**输出**：学到的东西能不能变成我亲手写出来的、能跑的东西？

判断标准很简单：讲得清但写不出，就还是没会。

## 每篇的固定结构

- **目标**：这次要造出什么，验收标准是什么
- **代码**：完整可跑，不是片段
- **踩坑**：错了什么、怎么发现、怎么修
- **检验题**：换个情境问"这里会发生什么"——答不上来说明只是抄会了，不是学会了

> 基础线的进度同步在[学习周记](/weekly/)里，这里是成品沉淀。
