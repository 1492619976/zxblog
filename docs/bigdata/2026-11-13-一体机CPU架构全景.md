# 2026-11-13 一体机CPU架构全景

**问题**：一体机有 ARM 架构，还有哪些？

**结论**：一体机（整机形态词，与架构正交）CPU 指令集共五大阵营——

1. **x86** — Intel Xeon / AMD EPYC；国产：海光（AMD Zen 授权衍生）、兆芯（VIA 授权）。存量生态最厚，软件零改造
2. **ARM** — 华为鲲鹏920、飞腾（腾云S/腾锐D）；国际 Ampere、NVIDIA Grace。能效优，服务器软件需重编译但主流栈已齐
3. **LoongArch** — 龙芯 2021 自研指令集（前身 MIPS），3A6000 桌面 / 3C6000 服务器；自主度最高，生态自建中
4. **SW64** — 申威，DEC Alpha 演化，神威·太湖之光同源；超算强、通用商用生态最薄
5. **RISC-V** — 开放指令集免授权费；IoT/NPU/MCU 已落地，服务器整机早期

国际小众：POWER（IBM 小型机）；历史退役：MIPS / SPARC / Alpha / 安腾。

**AI 一体机 = CPU × 加速卡组合**（两层架构别混）：鲲鹏+昇腾（"ARM 一体机"常指这套）/ x86+NVIDIA（市占最大）/ 海光+DCU（信创全栈）/ 寒武纪等国产卡 / Apple M 统一内存 / GB200 Grace（ARM）+Blackwell——AI 旗舰整机 CPU 也在转 ARM。

**类比**：指令集=清溪镇行话，生态=镇上有多少师傅听得懂；老陈面包房三十年不换烤炉=菜谱（软件）都按这台炉子写的，换架构=菜谱全重写=软件迁移成本。
